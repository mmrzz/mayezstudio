# Mayez

Website for mayez studio. Vanilla Vite project (no framework); see `package.json` for scripts.

## Working rules

- Read `decisions.md` (imported below) before starting any task.
- Do not contradict an Active decision without asking the user first. If a request conflicts with one, say so.
- Never edit `decisions.md` on your own. When a conversation reaches a final decision, suggest an entry (draft it in chat) and let the user decide whether to add it. Write to the file only when the user explicitly asks.
- Entries record the final result and the factors behind it, never the back-and-forth of the conversation.
- Use `var(--token)` for every color. No hardcoded colors in components.
